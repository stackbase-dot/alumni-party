■ステップ1：GitHubアカウントを作る

github.com にアクセス
画面右上の 「Sign up」 をクリック
メールアドレスを入力
パスワードを設定
ユーザー名（英数字）を決める
例：stackbase-dot など
これがURLに使われます：https://stackbase-dot.github.io/


■ステップ2：リポジトリ（保管場所）を作る

ログイン後、画面左上の 「＋」 → 「New repository」 をクリック
Repository name に名前を入力
例：alumni-party
英語で入力してください

Public（公開）を選択（無料プランではPublicが必要）
「Create repository」 をクリック


■ステップ3：HTMLファイルをアップロードする
リポジトリができたら、ファイルをアップロードします。

リポジトリの画面で 「uploading an existing file」 のリンクをクリック
または 「Add file」 → 「Upload files」


「choose your files」 をクリック
先ほど作成した 2026_alumni-party.html を選択
画面下部の 「Commit changes」 をクリック
これでファイルがアップロードされます


■ステップ4：GitHub Pagesで公開する
ファイルがアップロードされたら、公開設定をします。

リポジトリの画面で 「Settings」（歯車アイコン）をクリック
左側のメニューから 「Pages」 をクリック
Branch の項目で、「main」 を選択
「Save」 をクリック
数秒後、緑色のボックスにURLが表示されます：
例：https://stackbase-dot.github.io/alumni-party/
このURLがあなたのホームページのアドレスです

■ステップ5：ファイル名を index.html にする（重要）
GitHub Pagesは、index.html という名前のファイルを自動的にトップページとして認識します。
今のアップロードしたファイル名は日本語なので、以下のように変更してください。

リポジトリのファイル一覧で、アップロードしたHTMLファイルをクリック
右上の 「...」（3つの点）をクリック
「Rename」 を選択
ファイル名を index.html に変更
「Commit changes...」 → 「Commit changes」 をクリック

これで、https://stackbase-dot.github.io/alumni-party/ にアクセスすると、ページが表示されます。


■ステップ6：QRコードを作る

QRコード生成サイト（例：QR Code Generator）を開く
GitHub PagesのURL（例：https://stackbase-dot.github.io/alumni-party/）を入力
QRコードを生成・ダウンロード
印刷してプレートに貼る


写真公開時の更新方法
Googleフォトのリンクができたら、HTMLファイルを更新する必要があります。

リポジトリの index.html をクリック
右上の 「Edit this file」（鉛筆アイコン）をクリック
ボタンの部分を編集（コメントアウトされている有効なリンクに差し替え）
画面下部の 「Commit changes...」 → 「Commit changes」 をクリック
数分後、ページが自動更新されます




年末にサイトを削除する方法
方法A：ページの公開を止めるだけ（ファイルは残す）

リポジトリの 「Settings」 → 「Pages」
Branchの 「None」 を選択 → 「Save」
URLにアクセスしても表示されなくなります

方法B：完全に削除する

リポジトリの 「Settings」 を開く
一番下までスクロールして 「Danger Zone」 を表示
「Delete this repository」 をクリック
確認のためリポジトリ名を入力
「I understand the consequences, delete this repository」 をクリック
完全に削除されます
